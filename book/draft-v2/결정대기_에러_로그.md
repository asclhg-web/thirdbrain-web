## C. 권한 설정 변경 내역 (오늘 적용)

`.claude/settings.json` (프로젝트 설정)에 허용 목록 신설 — 이제 아래 작업은 확인 창 없이 진행됩니다:

- Google Drive: 파일 생성·검색·목록·메타데이터·읽기 (5종)
- 파일 도구: Write, Edit, SendUserFile, Artifact
- Bash: `python3 *`(D-02 참고), `pip install *`, `git add/commit`, `git push -u origin claude/*`(작업 브랜치 한정), `mkdir -p`, `base64`, `split`

**주의**: 이 설정은 이 저장소(thirdbrain-web) 세션에만 적용됩니다. 그래도 창이 뜨는 경우는 ① 위 목록 밖의 새로운 도구이거나 ② claude.ai 커넥터 자체의 1회 승인 창입니다 — 그때 "항상 허용"을 눌러 주시면 됩니다(D-01).
