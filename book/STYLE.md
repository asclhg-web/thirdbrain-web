# 집필 스타일 가이드 (모든 챕터 공통)

## 형식 규칙 (pandoc → docx 변환 전제)
- 각 챕터 파일은 `# 제N장. 제목` (H1) 하나로 시작. 절은 `##`, 소절은 `###`.
- 부 표지는 별도 파일에서 처리하므로 챕터 파일에는 부 제목을 넣지 않는다.
- 표는 markdown pipe table. 셀 안에 줄바꿈 금지, 간결하게.
- 그림 대신 텍스트 다이어그램(코드블록)과 표를 활용.
- 인용문은 `>` blockquote. 각 장 도입부에 관련 명언/연구 인용 1개 권장.
- 참고문헌 인용은 본문 내 (저자, 연도) 형식. 예: (Davenport, 1998), (Nonaka & Takeuchi, 1995). 장 끝에 "이 장의 참고문헌" 절을 두고 서지사항 나열.
- 사례 박스: `> **사례** ...` 형식의 blockquote로 처리.
- 각 장 끝에 "핵심 요약" 절(불릿 5-7개)을 둔다.

## 문체
- 존댓말이 아닌 학술서 문어체 ("~이다", "~할 수 있다").
- 철학적 깊이와 실무적 구체성의 균형. 개념을 소개할 때는 반드시 기원(누가, 언제, 왜)을 밝힌다.
- 과장 금지. Odoo의 단점·한계도 정직하게 다룬다 (2부 각 장에 단점 절 필수).
- 숫자·성과는 출처와 함께. 확인 안 된 수치는 "~로 알려져 있다" 대신 아예 쓰지 않거나 출처 명시.
- 한 문단은 3-6문장. 개조식 남발 금지 — 서술 중심에 표·불릿은 보조.
- 영문 용어는 첫 등장 시 "온톨로지(ontology)" 형식, 이후 한글만.

## 분량
- 지시된 페이지 수 × 약 1,400자(공백 포함)를 목표로 한다. 예: 10p 챕터 ≈ 14,000자 이상.
