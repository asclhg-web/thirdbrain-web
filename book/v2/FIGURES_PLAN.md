# 『AI ERP 혁명 — Odoo와 지능형 ERP』 챕터별 그림·표 구성안

각 장의 내용을 쉽고 보기 좋게 만들기 위한 시각자료 계획이다.
- **그림** = 디자이너/파워포인트로 그릴 도해(圖解). 형식을 함께 표기: 구조도·순서도·루프도·매트릭스·타임라인·차트·비교도
- **표** = 워드 표로 정리할 것 (✔ = 원고에 이미 있음 → 서식만 다듬으면 됨 / ★ = 새로 추가 권장)
- 그림 번호는 「그림 장-번호」 규칙 (예: 그림 5-2)
