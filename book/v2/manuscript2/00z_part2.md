# 제2부. Odoo 플랫폼과 지능형 ERP의 적용 — 모듈별 경영컨설팅

> 제1부가 방법론이라면 제2부는 적용이다. Odoo의 각 모듈을 컨설팅의 언어로 다시 읽는다 — 이 모듈은 어떤 경영 질문에 답하는가, 어떤 데이터를 3정5S로 정비해야 하는가, 눈으로 보는 관리의 세 단계는 어떻게 구현되는가, DMAIC 루프와 지능형 AI는 무엇을 더하는가, 그리고 컨설턴트는 무엇을 진단하고 어떤 순서로 구축하며 무엇으로 성공을 판정하는가. 웹사이트에서 회계까지, 그리고 Odoo AI와 서드브레인 부스터까지 — 플랫폼 전체를 경영의 지도 위에 올린다.
