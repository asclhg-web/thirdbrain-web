# AI ERP 혁명

## Odoo와 지능형 ERP — 제2부

**Odoo 플랫폼과 지능형 ERP의 적용: 모듈별 경영컨설팅**

&nbsp;

&nbsp;

# 일러두기

- 이 책은 『AI ERP 혁명 — Odoo와 지능형 ERP』 연작의 두 번째 묶음으로, 제2부(8~17장)를 담고 있다. 프롤로그와 제1부(지능형 ERP 컨설팅 방법론, 1~7장)는 첫 번째 묶음에, 제3부(부문별 온톨로지 메커니즘과 성과 사례)는 다음 묶음에 담긴다.
- 제2부의 각 모듈 장은 기능 소개서가 아니라 컨설팅 실행서로 쓰였다. 모든 장이 같은 8절 구조 — 경영의 질문, 기능 해부, 데이터 지도와 3정5S, 눈으로 보는 관리의 적용, DMAIC 루프 시나리오, 지능형 AI 적용 포인트, 컨설팅 가이드, 정직한 평가 — 를 따르며, 제1부에서 정립한 방법론(데이터의 3정5S, 눈으로 보는 관리 3단계, DMAIC 데이터 루프, AX 5단계 로드맵, 온톨로지 예측 플랫폼)을 각 모듈에 일관되게 적용한다.
- Odoo의 기능 서술은 Odoo 공식 소개자료(2026)와 공개 문서를 근거로 하였다.
