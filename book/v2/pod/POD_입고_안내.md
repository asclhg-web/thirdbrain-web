# 『AI ERP 혁명 — Odoo와 지능형 ERP』 교보문고 POD 입고 파일 안내

## 파일 구성

| 파일 | 용도 | 사양 |
|------|------|------|
| `AI_ERP혁명_POD_본문_최종.pdf` | 본문 인쇄용(입고 파일) | 신국판 152×225mm, **총 210쪽(짝수)**, 목차 10.5pt·2쪽, 컬러, 전 폰트 임베딩, 그림·표 가운데 정렬·개별 크기 최적화(`design_fit.py`+`extra.json`) |
| `AI_ERP_혁명_POD_표지.pdf` | 표지 인쇄용 | 펼침 322×231mm = 뒤표지 152 + 책등 12 + 앞표지 152, 상하좌우 재단 여분 3mm |
| `AI_ERP_혁명_POD_본문.docx` | 본문 원본(수정용) | `build_pod.sh`로 재생성 가능 |
| `AI_ERP_혁명_POD_표지.svg` / `표지_미리보기.png` | 표지 원본·미리보기 | `figures/make_pod_cover.py`로 재생성 |

## 조판 사양

- 본문 서체: **나눔명조 10pt**(본문) / **나눔고딕**(장·절 제목) — 모두 PDF에 서브셋 임베딩(OFL 라이선스, 상업 인쇄 가능)
- 여백: 상하 20mm, 좌우 18mm / 하단 중앙 쪽번호
- 그림 약 70점 + 표 54점(디자인 그림으로 렌더링) + 표지 아트 — 컬러(POD 신청 시 "컬러 인쇄" 선택)
- 일부 한자(躾 등)와 특수기호는 나눔명조에 글리프가 없어 대체 폰트로 임베딩됨 — 인쇄에는 문제 없음

## 책등(세네카) 폭 계산

- 210쪽 ÷ 2 = 105장 × 백색모조 100g/㎡ 두께(약 0.11mm) ≈ **11.6mm → 12mm 적용**
- 용지를 다르게 선택하면(미색모조 95g 등) 책등 폭이 달라지므로, 입고 시 교보 POD(퍼플)가 안내하는
  계산값과 다르면 `figures/make_pod_cover.py`의 `SPINE` 값만 바꿔 (현재 12mm) 재생성하면 된다.

## 입고 전 확인 사항 (직접 해야 하는 것)

1. **ISBN 발급** — 출판사(에이에스씨) 명의로 서지정보유통지원시스템에서 발급 후,
   뒤표지 좌하단 흰 박스(ISBN·바코드 자리)에 발급 바코드를 배치해 표지를 재생성.
2. **판권지(간기면)** — 발행일·발행처·ISBN·저작권 문구를 담은 판권 페이지를 본문 마지막에 추가 권장.
3. **가격** — 뒤표지 "값 00,000원"을 실제 정가로 수정.
4. 교보 POD 입고 규격(파일 크기 상한·PDF 버전 등)은 업로드 화면의 최신 안내를 따를 것.
