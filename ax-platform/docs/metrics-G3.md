# 모델 지표 합의 (G3)

## 1. 성능 요약 — 수기 대비 무엇이 얼마나 나아지는가

| 모델 | 지표 | 출발선(수기 근사) | 달성(데모) | 사업 번역 |
|---|---|---|---|---|
| 수요예측(GBDT) | WAPE | 20.0% (지수평활) | **8.2%** | 발주 오차 59% 감소 → Twin 추정 재고비용 11%↓, 폐기 9%→6% |
| 수요예측 | MAPE(floor5) | 20.7% | 9.6% | 품목별 편차 안정 |
| 불량분류 | AUC | 0.5 (무모델) | 0.73 (로지스틱 승) | 고위험 MO 사전 표시 — 4M 점검 우선순위 |
| 이상탐지(OVEN-2) | 선행 감지 | 사후 인지 | 고장 1/1건, **13일 선행** | 계획 정비 전환 — 정지 320분 회피 후보 |
| 재고 정책(Twin) | 일 비용 | 기준선 16,846원 | **14,981원 (−11.1%)** | 서비스 96% 유지, 폐기 9%→6% |

검증 방식: 수요예측 = 시계열 롤링 4폴드×28일(셔플 금지) · 분류 = 시간 분할
· 이상탐지 = 정상 구간 학습→전 구간 점수화 · 정책 = Twin 재생 검증 통과 후 탐색.

## 2. 검증 함정 점검

| 점검 | 결과 |
|---|---|
| 시계열 분할 준수(무작위 셔플 없음) | ✔ 하네스가 롤링 창만 허용 |
| 특징 누출(미래 정보) | ✔ point-in-time 강제 + 자동 시험(test_point_in_time_features) |
| 구간 대표성 | ✔ 4폴드가 명절·프로모션 포함 구간을 커버 |
| 소량 판매 MAPE 폭주 | ✔ 분모 하한(floor=5) 명시 |
| RL 안전장치 | ✔ Twin 밖 학습 경로 없음 · 기준선 미달 정책 상신 차단(propose→None) |

## 3. 운영 투입 조건 (초안 — 회의 합의 대상)

- 그림자 모드 **2주** 후 실승인 전환 (데모는 압축 시연).
- 재학습 **주 1회** — `learn/retrain.py`로 코드화됨: 트리거(드리프트 경보 2+
  또는 28일 홀드아웃 WAPE 12% 초과) → 재학습 → 그림자 비교 → **이긴 버전만 승격**
  (불통과 시 자동 롤백, retrain_log에 수치 근거).
- 자동 실행(승급)은 `agents/promotion.py` 조건부: 금액 상한 + 최근 승인율 기준,
  위반 시 자동 강등 — 감사 로그에 승급 번호·조건 명시.
- 예측 구간(P10~P90)을 카드에 상시 병기 — 단일 숫자 보고 금지.
