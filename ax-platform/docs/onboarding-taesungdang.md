# 태성당 온보딩 준비서 — 구조 적용 완료, 실데이터 대기

상태: **프로파일 적용·전 구간 검증 완료(합성 거래)**. 남은 것은 실데이터 원천
연결 — 아래 자료 요청서(D)가 그 열쇠다.
근거: 프로파일 `demo/profiles.py::taesungdang`, 실행 `python -m demo.run_taesungdang`,
산출 `customers/taesungdang/out/`.

> 정직 고지: 이 적용의 회사 **구조**(매장·제품·채널·어휘)는 제안 작업에서 확인된
> 실제 정보이고, **거래 수치는 전부 합성**이다. <확인 필요> 표시는 태성당
> 확인 전까지 가정이다.

| 항목 | 적용 값 | 상태 |
|---|---|---|
| 회사 | 주식회사 태성당 (1950 창업, 부산 초량) | 확인됨 |
| 매장 | 초량 본점(S-CHORYANG) · 별빛샌드 부산점(S-STAR-BS) · 별빛샌드 대구점(S-STAR-DG) | 확인됨(지점 수 재확인) |
| B2B 채널 | 선물세트·기업 납품(B2B-GIFT) | <확인 필요 — 거래처 목록> |
| 제품 | 파이만쥬(주력·명절 급증) · 별빛샌드 · 단팥빵 · 크림빵 | 확인됨 |
| 제품(추정) | 카스테라 · 우유식빵 | <확인 필요 — 실제 주력 8~12품목> |

| 현장 어휘 시드 | 본점/초량→S-CHORYANG · 만쥬→P-PIE · 샌드→P-SAND 등 11건 | 워크숍에서 확장 |

## B. 합성 거래 검증 결과 (구조가 실데이터를 받을 준비가 됐다는 증거)

| 검증 | 결과 |
|---|---|
| 수직 완주 | 64초 — 수집→표준화→학습→그래프→판단→환류 전 구간 |
| 수요예측 | WAPE **7.1%** (수기 근사 19.4%) — 파이만쥬·별빛샌드 포함 6품목 |
| 첫 환류 카드 | `forecast_qty:S-CHORYANG:P-PIE` — 초량 본점 파이만쥬 7일 발주 |
| 원인→지식 | 파이만쥬 라인(OVEN-2)×팥앙금 V2 로트 규칙 승격 → SOP-PIE-05 개정 제안 승인 |
| 설비예지 | 고장 13일 선행 감지 · 정상 설비 오경보율 2.8% |
| G4 수용 | 6/6 영역 통과 · 회귀 질의 10/10 · 품질 게이트 통과(미매핑 0.11%) |

## C. 실데이터 전환 절차 (스왑 3단계)

1. **Odoo 연결** — `core/axp/ingest/odoo_cdc_prod.sql`을 태성당 Odoo DB에 적용
   (버전·quality/maintenance 모듈 유무 확인 → 없으면 품질·정비는 장표 폼으로 시작).
2. **엑셀·장표 반입** — D의 파일들을 `inbox/`에 넣고 업로더 1회 매핑(이후 자동).
   장표 3종(생산일지·오븐 점검표·마감 폐기 장부)은 폼 필드만 현장 어휘로 조정.
3. **재실행** — 같은 명령(`run_taesungdang`)에서 생성기 호출만 커넥터로 교체.
   계약·게이트·에이전트·승인함은 그대로 — 이것이 프로파일 설계의 목적이다.
