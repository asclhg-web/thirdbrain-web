## 회고 (데모 구축)

**잘된 것**
1. 얇은 수직 완주가 실제로 얇았다 — 72초에 M0→M7 전 구간이 돈다.
2. 심어 둔 원인(OVEN-2×V2)을 파이프라인이 스스로 찾아 Rule로 승격시켰다 —
   마이닝(z=32) → 후보 → 3회 확인(확신도 88%) → 상신 카드 → 사람 승인.
3. 규율의 코드화 — 인용 없는 문장·근거 없는 카드·카드 없는 모델·승인 없는
   반출/환류가 전부 예외로 죽는다. 문서가 아니라 구조가 지킨다.

**문제였던 것** (ISSUES.md 상세)
1. 이상탐지 첫 학습이 드리프트 구간을 정상으로 삼았다 → 정상 구간 정의를
   정비 이력 기준으로 강제, 센서 이력 180일 확보.
2. Twin 재생 검증 1차 실패 — 예측열이 현장 발주 관행(같은 요일)과 달랐다 →
   재생은 dow 예측으로, 탐색은 그 위에서.
3. 인용 검증기의 백분율 오탐 — 표기 변환 허용 목록 필요.

**2단계 범위 초안**: 재고·생산(배분·보충 상시화) + 설비예지 앱 탑재,
이상탐지 설비 확대, RL 정책 월 1회 재탐색, 승급 1건 시험 가동.
