# 운영 가이드 — 플랫폼이 돌기 시작한 뒤

일·주·격주 리듬. 각 절차는 프롬프트집(OP-1~6)과 1:1로 대응한다.

## 일 단위

| 시각 | 일 | 명령/화면 | 담당 |
|---|---|---|---|
| 야간 | 정합 배치 + 변환 + 마이닝 | scheduler가 자동: `odoo_cdc.reconcile`(demo) / `odoo_cdc.reconcile_prod`(실 Odoo — 뷰 대비 건수·합계, 삭제 고아 적발) → `transform.run_all` → `mining.nightly` | 자동 |
| 07:00 | 아침 브리핑 발행 | `briefing.run_nightly_and_brief(오늘)` → 메신저 | 자동 |
| 07:30 | 아침 회의 | 현장 보드(field_board) 순서로 | 현장 리더 |
| 오전 | 품질 리포트 조치 | `quality.daily_report` 위반 → 격리 큐 확정(`codemap.confirm`) | **스튜어드** |
| 수시 | 승인함 처리 | /cards 대기 카드 검토·승인/반려(사유 필수) | **카드 승인자** |

## 주 단위

- **재학습·드리프트 점검(OP-3)**: `drift.input_drift` → PSI 경보 2+ 또는 WAPE 하한
  초과 시 `forecast.train_and_register`(새 버전) → 그림자 1주 → `cards.promote`.
- **War Room 리뷰(OP-4)**: `/warroom?as_of=` 화면 순서대로 — KPI → 반려 사유 →
  에이전트 오류 → 드리프트 → 승급/강등 결정. 회의록에 결정만 남긴다.
- **백업 확인**: backup.sh 로그 3본 확인 (실패 경보 없더라도 주 1회 육안).

## 격주·분기

- **리스크 5 점검(OP-5)**: 신규 양식 유입·요구서 없는 기능·Twin 밖 학습 흔적·
  회귀 10선·스튜어드 단독 수행 수. 녹/황/적 판정.
- **분기 복구 시험**: deploy/backup/restore-drill.md 절차 그대로. 기록 필수.

## 하지 말 것

- 격리 큐 우회 강제 매핑 · 카드 없는 모델 배포 · 승인 없는 파라미터 변경 ·
  게이트 없는 외부 전송 · 회귀 시험 없는 LLM/모델 교체 — 전부 코드가 막지만,
  막힌 것을 우회하려는 순간이 바로 사고의 입구다. 우회 대신 계약을 고쳐라(PR).
