## 1. 수집하는 항목과 목적

| 항목 | 목적 | 보유 기간 |
|---|---|---|
| 회사명·담당자명·이메일 (체험 신청) | 체험 계정 발급·안내 연락 | 체험 종료 후 3개월 |
| 로그인 계정·접속 기록(감사 로그) | 보안·부정 사용 방지 | 계정 파기 시까지 |
| 업로드 파일 | 이용자 본인의 데이터 체험 | **24시간 내 자동 파기** |

수집하지 않는 것: 주민등록번호·전화번호(선택 기재 시에도 저장하지 않음)·
결제 정보(체험판 무상)·쿠키 기반 광고 추적(추적 스크립트 없음).

## 2. 자동 차단 장치

업로드 파일에서 개인정보로 의심되는 컬럼(전화·휴대폰·연락처·이메일·주민·
생년월일·카드번호·계좌·주소 등)은 **반입 시점에 자동 삭제**되며, 값은 로그에도
남기지 않는다(컬럼명만 경고 기록). 차단 목록은 계약 시 고객 요청으로 확장한다.

## 3. 처리 위탁·제3자 제공

- 제3자 제공 없음. 광고·분석 목적 공유 없음.
- 인프라 위탁: Cloudflare(DNS·TLS 종단·트래픽 중계 — 캐시에 개인정보 저장 없음),
  자사 보유 서버(대한민국 소재, 데이터 보관 주체).
- 정식 계약 고객의 운영 데이터는 **고객사 소유·고객 지정 서버(온프레미스 포함)**
  에 저장된다 — 데이터 주권은 계약서·SLA에 명시.

## 4. 파기 절차

- 업로드 파일: 매시 자동 파기 배치(24시간 시효) — 기술적 구현: tenant purge-uploads.
- 체험 환경 전체: 매일 0시 초기화 + 체험 종료 시 테넌트 파기(디렉터리·DB 스키마 동시).
- 신청 정보: 보유 기간 경과 시 이메일 스레드 삭제.
