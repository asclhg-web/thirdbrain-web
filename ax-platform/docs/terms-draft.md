# AX 플랫폼 체험판 이용약관 초안 v0.1 (P4-8 — 법률 검토 전)

> 게시 전 법률 검토 필수(사용자 결정 ④ 미결). try.odooaierp.com 체험판 대상.
> 정식 서비스 약관은 파일럿 계약서·SLA(sla-draft.md)가 우선한다.

## 1. 목적과 정의

- "체험판"은 에이에스씨(ASC)가 try.odooaierp.com 에서 무상 제공하는
  AX 플랫폼 평가용 서비스를 말한다.
- 체험판의 기본 데이터는 **합성 데이터**이며, 화면의 모든 수치는 실제
  거래·실적이 아니다(화면에 상시 고지).

## 2. 계정

- 체험 계정은 신청 후 승인제로 발급되며, 1개 회사당 1계정을 원칙으로 한다.
- 계정 양도·공유 금지. 비밀번호 관리 책임은 이용자에게 있다(최초 로그인 시
  변경 안내, 5회 실패 시 15분 잠금).
- ASC는 부정 사용·과도한 부하 유발 시 사전 통지 없이 계정을 정지할 수 있다.

## 3. 체험 데이터와 업로드 파일

- 체험 환경은 **매일 0시(KST) 초기화**된다 — 작업물은 보존되지 않는다.
- 이용자가 올린 파일(엑셀·POS 정산 등)은 **업로드 후 24시간 내 자동 파기**되며,
  모델 학습·다른 고객 서비스에 사용하지 않는다.
- 개인정보로 의심되는 컬럼(연락처·주소·계좌 등)은 반입 시점에 자동 차단된다 —
  그럼에도 개인정보가 포함되지 않도록 업로드 전 확인할 책임은 이용자에게 있다.

## 4. 금지 행위

타인 정보 업로드, 서비스 역설계·취약점 스캔, 자동화 대량 요청,
법령 위반 데이터 업로드.

## 5. 보증의 부인·책임 제한

- 체험판은 "있는 그대로" 제공되며 가용성·정확성을 보증하지 않는다.
- 체험판의 판단 카드·예측치는 **제안**이며, 이를 근거로 한 사업 결정의 결과에
  대해 ASC는 책임지지 않는다. 발주·생산 확정은 언제나 이용자의 판단이다.
- 무상 서비스로서 ASC의 배상 책임은 법이 허용하는 한도에서 배제된다.
