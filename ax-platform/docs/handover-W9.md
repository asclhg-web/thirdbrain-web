# W9 인수인계 체크리스트 — 자립의 최종 검수

원칙: 검수 실패 항목이 남으면 종료가 아니다. '추후 지원하겠다'로 종결 금지 —
보완 후 재검수만 있다.

## A. 자산 이관 (커스터디 헌장 1·4조)

- [ ] 자산 대장(asset_ledger) 전 항목의 위치·접근권·최신성 — 대장에 없는 산출물 0건
- [ ] 스키마 레지스트리(registry/) 사내 Git 이관 + PR 승인권을 스튜어드로 교체
- [ ] 모델 아티팩트(artifacts/models)와 카드 전 버전 이관
- [ ] 지식그래프 내보내기(kg_export.cypher) 최신본 + Neo4j 적재 확인
- [ ] 문서 세트: runbook · auth-roles · restore-drill · install/operations-guide ·
      G1~G4 · 프롬프트집 — 전부 발주사 저장소에

## B. 권한·계정 이양 (M0-2)

- [ ] Keycloak 관리자 계정 이양, 수행사 계정 비활성화
- [ ] 반출 게이트 승인자 → 스튜어드(또는 지정 임원)로 교체, 시험 반출 1건으로 확인
- [ ] 카드 승인자 그룹 재확인 — 수행사 인원 제외
- [ ] secrets 4파일 재발급(수행사가 알던 값 폐기)

## C. 스튜어드 단독 수행 시험 (4종 — 동석 없이, 기록 필수)

| # | 시험 | 절차 | 판정 |
|---|---|---|---|
| 1 | 재학습 1회 | OP-3 프롬프트대로: 드리프트 확인→train_and_register(new ver)→그림자 비교→promote | 새 모델 카드 등록·서빙 전환 |
| 2 | 카드 승인 1회 | 승인함에서 검토→'왜?' 경로 확인→승인→환류·감사 로그 확인 | odoo_params 반영 + audit_log |
| 3 | 대장 갱신 1회 | 신규 산출물 1건 ledger.register + 레지스트리 PR 병합 | 대장·Git 이력 |
| 4 | 백업 복구 1회 | restore-drill.md 절차 전체(스테이징) | RTO·RPO 기록, 검증 쿼리 3종 통과 |

## D. 운영 리듬 인계 확인

- [ ] 아침 브리핑·품질 리포트 수신자가 발주사 채널로
- [ ] War Room 주간 리뷰를 스튜어드가 1회 주재(수행사는 참관만)
- [ ] 리스크 5 점검(OP-5)의 다음 회차 일정이 발주사 달력에

## E. 최종 대사

- [ ] export_gate.reconcile() — 반출 로그·승인 일치, 미승인 실행 0건

- [ ] 회귀 질의 10선 통과(현재 버전 기준)
