# 첫 고객사 온보딩 준비서 — demo에서 실 데이터로

합성 데이터의 자리에 실 고객사 값을 넣는 절차. 제빵 프랜차이즈(예: 부산의
70년 제과 — 본점·분점·B2B 납품·파이만쥬류 주력)를 예시 값으로 적었다.
G1 헌장 서명 전 이 준비서의 A·B가 채워져 있어야 착수가 빠르다.

## A. 데이터 원천 실사 체크리스트 (M1)

## C. 코드 사전 시드 교체 (M2)

`axp/dataset/codemap.py`의 SEED를 실 별칭으로 교체한다 — 초기 30분 워크숍에서
스튜어드와 화이트보드로 뽑는 것이 가장 빠르다:
매장 별칭(현장 호칭), 제품 별칭(POS 표기·현장 호칭·엑셀 표기 3벌), 원료 별칭.
표준 코드와 완전 일치하는 별칭은 자동 매핑되므로 시드는 '다르게 불리는 것'만.
