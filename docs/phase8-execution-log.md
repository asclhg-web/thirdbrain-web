원칙: 코어(M1~M7·측정 엔진·보안) 불변 — 화면 계층(webapp)만 재편, 기존
테스트 전체가 안전망. 블록마다 [구현→테스트 양쪽 백엔드→커밋] 완결.

| 블록 | 상태 | 내용·실측 |
|---|---|---|
| P8-1 정보구조 | **완료** | 14개 평면 메뉴 → 오늘/데이터/판단/성과 4허브 + 관리(admin만 노출) 2단 내비. 기존 주소 전부 보존. 역할별 홈(admin→오늘, steward→자료 반입, approver→승인함, viewer→프로젝트), '/'도 역할 홈. 테스트 3건 |
| P8-2 '오늘' 홈 | **완료** | /today — 승인 대기·확인할 이름·미달 KPI를 할 일 카드로 집계(각 1클릭 이동), 0건이면 '처리할 일 없음', 질문창 상시, admin에겐 시스템 링크. projects.underachieving() 신설. 테스트 2건 |
| P8-3 여정·빈 상태 | **완료** | 시작 여정 5단계 카드(회사→자료→프로젝트→목표→첫 측정, 완주 시 소멸), 자료 반입 파이프라인 한 줄(①업로드→②매핑→③확인할 이름 N건→④지금 반영+마지막 반영 시각), '지금 측정' 버튼을 제목 옆 큰 버튼으로 승격(대표 실사용 적발), 프로젝트 빈 상태 안내. 테스트 3건 |
| P8-4 모바일·알림 | **완료** | 640px 이하 탭 타깃·표 스크롤·입력 16px — 폰 승인 실사용 수준. 텔레그램 알림은 엔진 결선 기존 완료 — env 3행 주석 안내 추가(값만 넣으면 폰 수신) |
| P8-5 웹 완결 운영 | 대기 | 용어 순화 일괄(화면 본문), 관리자 운영 잔여(테넌트 관리 화면화). 한계 기록: admin 본인 비밀번호 분실은 웹만으로 불가(보안상 root 명령 유지가 설계) |
| P8-6 매뉴얼 v3 | 대기 | 새 화면 기준 재작성 — P8-5 후 착수. 그때까지 매뉴얼 v2.2·데모 영상은 구 화면 기준(불일치 고지) |
