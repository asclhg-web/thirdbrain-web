## P4-1: 체험 테넌트 도구 (2026-09-11)

`core/axp/tenant.py` + CLI `python3 -m axp.cli tenant create|reset|destroy|purge-uploads|list`.

- **create**: 템플릿(기본: 합성 T사 데이터 루트) 복제 → 프로파일 개명(trial 플래그)
  → 체험 계정 무작위 비밀번호 발급(0600, 반환값·목록에 비밀번호 노출 금지).
  실측: 119MB 템플릿 복제 1초 미만, 새 계정 로그인→승인함 렌더 확인.
- **reset**: 템플릿 재복제(개명 유지) — 매일 0시 초기화 크론용.
- **destroy**: 디렉터리 + **PG 스키마 동반 파기**(P3-I7 재발 방지 내장,
  식별자 정규식 검증 — P3-I8 LIKE 함정 회피).
- **purge-uploads**: raw/ 아래 시효(기본 24h) 지난 업로드 원본 삭제 —
  4단계 정직 조항("체험 파일 24시간 내 파기")의 구현체. 25h/신규 파일로 실측.
- 테스트 5종(개명·계정·중복/이름 규칙 거절, 리셋 오염 제거, 파기, 시효 파기,
  목록 비밀번호 은닉).

## P4-2: 웹앱 공개 보강 (2026-09-11)

- **로그인 시도 제한**: 실패 5회(AXP_LOCK_THRESHOLD) → 15분(AXP_LOCK_MINUTES) 잠금.
  잠금 중엔 올바른 비밀번호도 423으로 거절(실측). 존재하지 않는 계정도 동일
  동작 — 계정 존재 여부를 흘리지 않는다. 잠금 발생은 경보(warn)로 기록.
- **성공 시 카운터 소거** — 정상 사용자가 오타 몇 번으로 누적 잠금되지 않는다.
- **체험판 워터마크**: profile.trial=True면 전 화면 헤더에 '체험판 · 합성 데이터'
  상시 고지 + 회사명 표시(4단계 정직 조항 구현). 테넌트 도구의 trial 플래그와 연동.
- 테스트 4종 추가(잠금·유령 계정 동일 동작·소거·워터마크) + P4-I1 회귀 1종
