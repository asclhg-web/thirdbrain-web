# T29 — 실측정 데이터 연동 (갤럭시 워치8 + 혈압)

## 데이터 흐름

```
갤럭시 워치8 → 삼성헬스(휴대폰) → [개인 데이터 다운로드 zip]
  → OneDrive의 볼트 `피지컬브레인/인박스/`에 넣기 → 서버가 5분 내 자동 처리
혈압계 측정 → 대시보드 '혈압 입력' 폼 → 즉시 안전망 검사
```

## 가져오는 항목

| 원천 | 앱에 저장되는 것 |
|---|---|
| 심박 (연속 측정) | 일별 안정 심박(rhr) — 하루 최저값 근사 |
| 수면 | 밤별 수면 시간(h) |
| 걸음 | 일별 걸음 수 |
| 혈압 | 수동 입력 (수축/이완) — 135/85 주의·180/120 긴급 즉시 알림 |

운동(러닝 등) 세션·혈당은 v2에서 추가 예정. 워치의 혈압 측정값(헬스모니터 앱)은
내보내기가 제한적이라 폼 입력을 권장.

## 휴대폰에서 zip 만들기 (주 1회 권장)

1. **삼성헬스** 앱 → 우상단 ⋮(메뉴) → **설정** → 아래로 스크롤
2. **개인 데이터 다운로드** → 본인 인증 → 다운로드 (몇 분 소요)
3. 완료되면 휴대폰 `Download/Samsung Health/` 폴더에 zip 생성
4. 휴대폰 **OneDrive 앱** → 회사 계정 → `obsidian valt/피지컬브레인/인박스/` 폴더에 zip 업로드
   (인박스 폴더가 없으면 처음 1회 만들기)
5. 끝 — 서버가 5분 내 읽고, 처리된 파일은 `인박스/처리됨/`으로 이동

수동 실행(서버 PC): `python -m pipelines.samsung_health --zip 파일.zip`
