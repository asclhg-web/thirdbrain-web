# 데이터셋 스펙 v1 (T24) — 약 서빙 스킬 학습용

LeRobot(LeRobotDataset v2) 형식. 목표 스킬 2종을 모방학습(ACT)으로 훈련한다.

## 학습 대상 스킬

| 스킬 ID | 설명 | 시작 상태 | 종료 상태 | 성공 판정 |
|---|---|---|---|---|
| `pick_pillbox` | 약 선반에서 오늘 칸 약통 집기 | 그리퍼 빈손, 선반 앞 | 약통 파지, 들어올림 | 약통이 그리퍼에 5초 유지 |
| `serve_tray` | 약통을 트레이에 놓고 사람 앞으로 | 약통 파지 | 트레이 위 배치 완료 | 약통이 트레이 지정 구역 안 |

## 수집 규격

- **로봇**: LeKiwi(SO-101 팔 + 옴니휠 베이스), 리더암 텔레옵
- **카메라 2대**: 손목캠(wrist) + 정면 고정캠(front), 640×480, **30fps**
- **에피소드 길이**: 10~20초 (짧고 성공한 시연만)
- **수량(스킬당)**: 최소 50, 권장 100+ 에피소드
  - 배치 변화: 약통 위치 ±10cm, 3가지 조명(아침/낮/저녁 전등)
  - 실패 시연은 저장하지 않는다 (모방학습은 성공만 배운다)
- **관측/행동 키**: `observation.images.wrist`, `observation.images.front`,
  `observation.state`(관절각), `action`(목표 관절각)
