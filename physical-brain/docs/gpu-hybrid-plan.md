# GPU 하이브리드 운용 계획 (D-03 확정)

**결정: 집에 GPU PC 1대(상시 추론·비서) + 대량 학습만 클라우드 스팟.**
건강 데이터는 집을 떠나지 않고(로컬 퍼스트), 학습 비용은 쓴 만큼만 낸다.

## 1. 홈 서버 — 구매 가이드

| 구성 | 권장 | 대안(예산 절약) |
|---|---|---|
| GPU | RTX 4090 24GB (~250만) | RTX 4070 Ti SUPER 16GB (~110만) |
| CPU/RAM | 라이젠 7 + 64GB | 라이젠 5 + 32GB |
| 저장소 | NVMe 2TB (모델+데이터셋) | 1TB |
| 총액 | 약 400만 원 | 약 220만 원 |

- 24GB면 Ollama 대형 모델(qwen2.5:32b급) + STT medium + 학습을 한 대에서 소화.
- 16GB 대안: 추론(14b급)·STT는 충분, LeRobot ACT 학습도 가능(배치 축소).
- 설치: 우분투 22.04 → `bash docker/gpu-setup.sh --install` → `docker compose --profile gpu up -d`
- 원격 접근은 테일스케일 VPN만. 외부 포트 개방 금지.

## 2. 클라우드 스팟 — 학습 전용 (RunPod/Vast.ai)

쓰는 경우: 스킬 학습을 여러 설정으로 병렬 실험할 때, 홈 서버가 비서 업무로 바쁠 때.

```bash
# 1) 데이터셋만 올린다 (카메라 영상 = 로봇 팔·약통, 개인 건강 데이터 아님)
huggingface-cli upload $USER/pb_pick_pillbox_v1
# 2) 스팟 인스턴스(4090, ~$0.5/h)에서 런북 3단계(학습)만 실행 → 3~6시간 ≈ 3천 원
# 3) 체크포인트 내려받고 인스턴스 즉시 삭제
```

**원칙: 클라우드에는 로봇 시연 데이터셋과 모델 가중치만 올라간다.**
혈압·복약 등 건강 그래프(brain.db)는 어떤 경우에도 업로드하지 않는다.

## 3. 역할 분담 요약

| 작업 | 장소 | 근거 |
|---|---|---|
| AI 사서·브리핑·알림 (24/7) | 집 | 건강 데이터 주권, 전기료 월 2~3만 원 |
| STT/TTS (D-07 piper, D-08 medium) | 집 | 음성도 개인 데이터 |
| LeRobot 스킬 학습 (반복 실험) | 클라우드 스팟 | 시간당 과금이 유리, 개인정보 아님 |
| 학습된 정책 실행 (로봇) | 집 (젯슨/홈서버) | 지연시간·오프라인 동작 |
